# Screenshots (polish loop, docs/04_UI.md §12)

`npm run screens` writes a full-page screenshot of every screen here at 360, 768 and 1280 px, light and dark,
English and Bangla (`<screen>-<width>-<theme>-<lang>.png`). Narrow the set with `SCREEN_WIDTHS`,
`SCREEN_THEMES` and `SCREEN_LANGS` (comma-separated). The PNG files are not committed (about 30 MB per set).
